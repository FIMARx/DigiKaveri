# Security Policy

## 🔒 Supported Versions

Only the latest release running on the `main` branch is actively supported and maintained with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## 🛡️ Reporting a Vulnerability

The DigiKaveri team takes the security of our services and our customers' data very seriously.

If you discover a security vulnerability or sensitive information exposure:

1. **Do NOT** open a public issue on GitHub.
2. Please report the issue privately by emailing **[info@digikaveri.com](mailto:info@digikaveri.com)** with the subject line `[SECURITY] Vulnerability Report — DigiKaveri`.
3. Alternatively, submit a report via **[GitHub Private Vulnerability Reporting](https://github.com/FIMARx/DigiKaveri/security/advisories/new)** if available.

### Please include:
- A detailed description of the vulnerability and its potential impact.
- Step-by-step reproduction steps, proof-of-concept (PoC) scripts, or screenshots.
- The affected URL(s), API endpoints, or client components.

### What to expect:
- **Acknowledgment:** We will acknowledge receipt of your report within 48 hours.
- **Assessment & Fix:** We will triage the severity, develop a fix, and deploy it promptly.
- **Responsible Disclosure:** We kindly ask that you give us reasonable time to resolve the issue before public disclosure.
